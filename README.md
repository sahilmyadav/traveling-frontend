# Traveling — Frontend (React)

React frontend for the Traveling website project: a travel site UI with
routed pages built using Create React App.

Related repositories:

- Backend API: [traveling-backend](https://github.com/sahilmyadav/traveling-backend)
- Another frontend variant: [traveling-website](https://github.com/sahilmyadav/traveling-website)

## Tech Stack

- React, React Router
- Create React App tooling

## Getting Started

```bash
npm install
npm start
```

Runs on http://localhost:3000. Build for production with `npm run build`.
